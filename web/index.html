HTML 发布服务

选本机文件，审阅清单，再发布到公开网址。支持单个 HTML 或含 CSS、JS、图片的静态目录。

01 · 连接

连接 GitHub

目标仓库：jamiepak/html-publish-hub

尚未连接。Token 仅存在这个本机服务的进程内存中，关闭后清除。

在 GitHub 创建细粒度 Token，仓库只选 html-publish-hub，Contents 设为 Read and write。不要把 Token 发到聊天里。

02 · 选择

选择本机页面

目录根部需有 index.html。两种选择只用最后选中的一种；不会扫描其他本机文件。

同一个网址名再次发布会更新该页面。单次最多 100 个文件、总计 25 MB。

03 · 审阅并发布

确认公开内容
